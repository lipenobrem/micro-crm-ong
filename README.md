# 🤝 Micro-CRM para ONGs

Um sistema de Customer Relationship Management (CRM) leve e focado em Organizações Não Governamentais (ONGs), integrando gestão web e comunicação direta via WhatsApp. 

Este projeto foi desenvolvido como Projeto de Extensão do 4º semestre do curso de Análise e Desenvolvimento de Sistemas, com o objetivo de otimizar o atendimento e a gestão de contatos de instituições do terceiro setor.

## 🎯 Objetivo do Projeto
Fornecer às ONGs uma ferramenta acessível para gerenciar cadastros, monitorar interações e otimizar a comunicação diária através de um assistente virtual (chatbot) integrado ao WhatsApp, centralizando as informações em um Dashboard administrativo.

## ✨ Funcionalidades
- **Dashboard Web:** Interface administrativa intuitiva para visualização de métricas e gestão de dados da ONG.
- **Gestão de Cadastros:** Telas dedicadas e seguras para login e registro de informações de usuários e assistidos.
- **Integração com WhatsApp:** Atendimento automatizado utilizando um chatbot (`bot_routes`) para respostas rápidas e triagem.
- **Banco de Dados Local:** Armazenamento estruturado utilizando SQLite para fácil manutenção e deploy.
